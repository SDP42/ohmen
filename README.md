# OHMEN — Ω

**See the cascade before it happens.**

OHMEN is an AI-assisted cyber-risk digital twin for critical infrastructure, built for **D3COY PS 03: AI-Based Critical Infrastructure Cyber-Risk Prediction**. It connects asset inventories, vulnerability intelligence, network activity and operational dependencies to predict which assets matter most, simulate what fails next and show which fix removes the most risk.
